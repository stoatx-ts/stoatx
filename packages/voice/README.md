# @stoatx/voice

The shared voice connection and manager behind [`@stoatx/voice-node`](https://www.npmjs.com/package/@stoatx/voice-node) and [`@stoatx/voice-browser`](https://www.npmjs.com/package/@stoatx/voice-browser). You don't need to install it yourself: install the package for your platform instead.
