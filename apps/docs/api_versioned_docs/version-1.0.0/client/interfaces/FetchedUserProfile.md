# Interface: FetchedUserProfile

A user's profile, from [User.fetchProfile](../classes/User.md#fetchprofile).

## Properties

### background

> **background**: [`Attachment`](../classes/Attachment.md) \| `null`

The profile's background image, or `null` if there isn't one.

***

### content

> **content**: `string` \| `null`

The profile's text ("about me"), or `null` if empty.
