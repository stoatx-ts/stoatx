# Function: applyOverride()

> **applyOverride**(`value`, `override`): `bigint`

Applies an override: its allowed permissions are added, then its denied ones removed.

## Parameters

| Parameter | Type |
| ------ | ------ |
| `value` | `bigint` |
| `override` | [`PermissionOverride`](../interfaces/PermissionOverride.md) |

## Returns

`bigint`
